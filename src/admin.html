How detection works (and its limits)

  • Every homepage request is logged at Netlify's edge, including bots that never run JavaScript. Known crawlers, link-preview fetchers, AI crawlers, SEO tools, monitors and scripts are recognised by their user agent.
  • Human = the page ran in a real browser and the visitor touched, clicked, typed or moved the mouse naturally. Browsing fast is never counted against anyone.
  • Bot = a known bot user agent, an automated/headless browser (webdriver), no JavaScript with non-browser headers, or very frequent repeated requests from one network with no human interaction.
  • Uncertain = could not be decided confidently: the page was requested but JavaScript never ran (instant bounce, blocker, or a simple bot), or the page was open with no interaction.
  • No detection is 100% accurate: clever bots can imitate people, and some people use blockers. Treat the numbers as good estimates.
  • Privacy: no names, emails, IP addresses or fingerprints are stored. Networks are only compared within the same day using a salted hash that changes daily. Returning visitors are recognised by a random ID in the browser (skipped when Do Not Track / Global Privacy Control is on). Raw visit records are deleted after 90 days.
